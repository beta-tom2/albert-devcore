# Albert DevCore — каталог 33 опциональных специалистов

**Все 33 пакета в этом каталоге — внешние дополнения. Их файлы не включены в комплект ядра.** Архив содержит DevCore / ADOS и три собственных управляющих навыка. Ни наличие строки ниже, ни рекомендация Router не означают, что соответствующий специалист уже установлен у получателя.

Каталог составлен по инвентаризации набора на 4 ноября 2026 года и его источникам. Он помогает выбрать конкретные зависимости для отдельной оценки. Назначение в таблице — краткое описание ожидаемой области применения, а не сертификация всех scripts и runtime каждого пакета. Исходники, состав, условия распространения и поведение выбранной версии необходимо проверять вместе.

### Существенные различия процесса

У design-taste-frontend в реестре статус conditional-experimental, у apple-design и grilling — conditional. Это осознанные варианты применения. Выразительная стилистика, Apple-подобное взаимодействие и интерактивное интервью не должны автоматически определять каждую задачу.

При предыдущем чтении полных workflows improve-codebase-architecture и tdd обнаружены требования дополнительных согласований. Их нужно сопоставить с уже заданным пользователем объёмом работы и его правилами автономности. У tdd также есть ссылка на отдельный code-review этап; наличие необходимого компонента следует проверить у получателя.

unlazy — дополнение вне текущего реестра DevCore. Его отдельные планы, gates и журналы могут пересекаться с ADOS. Он не сделан обязательным слоем; его scripts и hooks не получают разрешение на запуск из одного факта наличия в каталоге. Полный runtime-аудит этого пакета в рамках подготовки комплекта не проводился.
